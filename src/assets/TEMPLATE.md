# Welcome to MarkdownView

A modern Markdown editor built with **Tauri** + **Vue 3** + **Vditor**.

## Features

- Split-view editing with live preview
- Syntax highlighting
- Outline navigation
- Dark / Light theme
- Tab-based multi-file editing

## Getting Started

1. Create a new file with `Ctrl+N`
2. Open an existing file with `Ctrl+O`
3. Save with `Ctrl+S`
