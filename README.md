

# MarkdownView

轻量级桌面 Markdown 编辑器，基于 Tauri 2 + Vue 3 + Vditor。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Shift+T` | 加载模板 |
| `Ctrl+N` | 新建文件 |
| `Ctrl+O` | 打开文件 |
| `Ctrl+S` | 保存文件 |
| `Ctrl+Shift+S` | 另存为 |
| `Ctrl+P` | 导出 PDF |
| `Ctrl+B` | 切换大纲 |
| `Ctrl+Shift+D` | 切换主题 |
