# Release v0.2.0 — Open Folder & Reading Mode

## Open Folder

- Workspace panel with recursive directory browsing and file tree
- Material file icons for files and folders
- Right-click context menu on files: open file location in system explorer
- Right-click context menu on tabs: close / close others / close all
- Multi-window support — open multiple workspaces simultaneously
- Drag & drop folders to open as workspace (current window or new window)
- Resizable file explorer panel (180–500px, width persisted)
- Prompt to choose current or new window when workspace already open

## Reading Mode

- Distraction-free view: disable editor, hide toolbar and word counter
- Hide tab bar for cleaner layout
- Keep outline pane visible for quick heading navigation
- Keep file explorer visible for switching between files
- Simplified AppBar: only reading mode button and theme toggle remain
- Shortcuts: `Ctrl+R` to toggle, `Escape` to exit

## Other Improvements

- Non-Markdown files open in CodeMirror 6 editor
- Vditor theme stays in sync with app theme on tab switch
- Outline pane updates correctly when opening files from explorer
- Various bug fixes and stability improvements
