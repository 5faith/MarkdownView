How it works

Open FileFile → tab in current window
Open FolderFolder → file tree sidebar in current window
Click file in treeOpens as tab (or switches to existing tab)
Close file treeClick × in tree header or 📁 toggle in AppBar
Active fileHighlighted in tree with blue background
Drag-drop fileOpens as tab (same as Open File)

Key design decisions

No separate window types. Every window is identical — the file tree is a toggle-able sidebar that appears when a folder is opened. Closing the tree hides it but remembers the folder path, so reopening is instant.

State model: workspacePath (folder path) and showFileTree (visibility) are independent. Toggle only changes visibility; opening a new folder resets both.
