# 编辑区宽度响应式（最小值 / 随屏增长 / 最大值）

## 目标

1. 编辑区内容宽度不再是固定 780px：窄屏有保底，窗口变宽时适度变宽，宽屏封顶。
2. 上限回归 `prd/style.md` §5 段 11 的 1200px 基准，避免宽屏两侧留白过多。

## 范围

- `src/styles/global.scss` 的 `--prose-width` 由固定 `55.714rem` 改为
  `clamp(55.714rem, 72vw, 85.714rem)`：
  - 最小值 55.714rem（1rem=14px 时 780px，等于原固定值）
  - 中间值 72vw，随窗口宽度线性增长
  - 最大值 85.714rem（1200px，与 `style.md` 基准一致）
- 最小/最大值用 rem，随 `--text-size` 等比缩放，保持行长字符数稳定；中间段用 vw 跟窗口。
- 编辑区被文件树/大纲压缩时，`width:auto` 仍会收缩到容器宽度，`max-width` 只作上限，不会溢出。
- `useExportPdf` 复用该变量：820px 导出 iframe 中 72vw=590px 落在下限，取值仍为 780px；打印媒体已 `max-width:none`，导出不受影响。

## 不做

- 不做用户可配置的宽度档位；不动编辑区 padding、文件树与大纲宽度。
- 不改 `style.md` 的 1200px 基准。

## 验证

- `pnpm build` 通过。
- 计算各窗口宽度下的取值：1280→921px，1440→1037px，1667 及以上→1200px 封顶。
- dev 实拉窗口宽度，检查编辑区内容宽度随窗口增长并在上限停住。
